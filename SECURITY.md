# Security policy

Report a vulnerability in this action through a private
[GitHub security advisory](https://github.com/TerraConstructs/run-aws-emulator/security/advisories/new).
Do not open a public issue.

Report a vulnerability in the image or its build through a private advisory on
[TerraConstructs/aws-emulator-docker](https://github.com/TerraConstructs/aws-emulator-docker/security/advisories/new).

Report a vulnerability in the AWS Emulator itself to AWS. See
[aws/aws-emulator](https://github.com/aws/aws-emulator/security/policy).
